# C# Quest

**C# Quest** - обучающая 3D-игра на Unity, в которой основы программирования на C# изучаются через игровые механики. Проект совмещает исследование уровней, взаимодействие с объектами, решение логических задач, управление игровыми системами и постепенное открытие нового контента.

Игра разработана как учебный проект: игрок не просто читает теорию, а применяет базовые идеи программирования внутри игрового мира. Условия, циклы, методы, параметры, наследование и работа с объектами представлены через двери, артефакты, терминалы, механизмы и роботов.

## Идея проекта

Цель проекта - показать, как обучение C# можно встроить в интерактивную 3D-среду. Вместо отдельных упражнений игрок проходит уровни, где каждая механика связана с определенной темой программирования:

- переменные и значения представлены через предметы и параметры игрока;
- условия используются для открытия дверей и проверки правильных комбинаций;
- циклы `for` и `while` превращены в управление техническими системами уровня;
- методы и способности выражены через действия игрока и роботов;
- наследование показано через разные типы роботов с общей базовой логикой и уникальным поведением;
- прогресс сохраняется между игровыми сессиями.

## Геймплей

Игрок перемещается по 3D-уровням, взаимодействует с объектами окружения, собирает предметы, активирует механизмы и выполняет задачи, связанные с основами C#.

Основной игровой цикл:

1. Исследовать уровень.
2. Найти интерактивные объекты или учебные элементы.
3. Применить нужную логику: подобрать значение, выполнить условие, активировать цикл или использовать подходящего робота.
4. Открыть проход, дверь или следующий этап.
5. Завершить уровень и открыть дальнейший прогресс.

Проект делает акцент не на запоминании синтаксиса, а на понимании принципов: что такое условие, зачем нужны циклы, как состояние объекта влияет на поведение сцены, как работает прогресс игрока.

## Уровни и механики

### Главное меню и прогресс

Проект содержит отдельную bootstrap-сцену с меню, выбором уровней и сохранением прогресса. После прохождения уровня следующий уровень становится доступен. Информация о завершенных и открытых уровнях хранится в локальном JSON-файле.

### Уровень с условиями и дверями

На уровне используются двери, которые открываются только при выполнении заданных условий. Игрок должен разместить нужные предметы или значения в слотах. Система проверяет выражения, сравнивает строки и числа, а затем открывает дверь при корректном результате.

Эта механика отражает работу условных операторов и логических выражений в C#.

### Уровень с циклами

Один из ключевых уровней построен вокруг управления шлюзовой или технической системой. Игрок управляет питанием, охлаждением, давлением, уровнем воды и подъемом ворот.

В этом уровне:

- `while` представлен как состояние, которое должно поддерживаться активным;
- `for` представлен как повторяемое действие с заданным числом итераций;
- инциденты требуют своевременной реакции игрока;
- прогресс уровня зависит от стабильности системы.

Это один из центральных учебных фрагментов проекта, так как программные конструкции напрямую связаны с игровыми действиями.

### Уровень с артефактами

На третьем уровне игрок собирает артефакты. Каждый артефакт реагирует на столкновение с игроком, исчезает после подбора, меняет визуальное состояние окружения и сообщает менеджеру уровня о сборе.

Когда все артефакты собраны, менеджер уровня открывает финальную дверь. Эта механика демонстрирует взаимодействие объектов, обработку событий и проверку завершенности задачи.

### Уровень с роботами и наследованием

В проекте реализована система роботов. Есть базовый класс робота и несколько специализированных типов:

- базовый робот;
- атакующий робот;
- робот-защитник;
- робот-лекарь.

Все роботы используют общую основу: здоровье, движение, поиск целей и боевую систему. Производные классы изменяют отдельные аспекты поведения. Например, робот-лекарь ищет поврежденных союзников и восстанавливает им здоровье.

Эта часть проекта показывает объектно-ориентированное программирование: наследование, переопределение поведения, конфигурацию через `ScriptableObject` и разделение логики на компоненты.

## Ключевые системы

### Система сохранения

В проекте реализовано локальное сохранение данных игрока и состояния сцены. Сохраняются:

- текущий уровень;
- позиция и поворот игрока;
- состояние объектов сцены;
- открытые двери и механизмы;
- прогресс роботов;
- прогресс уровней в меню.

Данные сохраняются в JSON-файлы через `Application.persistentDataPath`.

Подробное описание всех файлов сохранения, их структуры и примеров JSON:

- `SAVE_SYSTEM_README.md`

### Взаимодействие с объектами

Игрок взаимодействует с объектами через луч от камеры и систему ввода Unity Input System. Интерактивные объекты могут запускать анимации, активировать элементы уровня, открывать интерфейсы или передавать действие в управляющий скрипт.

### UI

Пользовательский интерфейс используется не только для меню, но и как часть обучения. UI показывает:

- состояние уровня;
- текущую фазу задачи;
- активность `for` и `while`;
- прогресс прохождения;
- подсказки по действиям;
- доступных роботов и их состояние разблокировки.

### Прогресс игрока

Прогресс игрока связан с прохождением уровней, сохранением состояния сцены и открытием новых возможностей. В меню отображаются доступные уровни, а внутри уровней сохраняются важные игровые изменения.

## Техническая информация

- Движок: Unity
- Версия Unity: `6000.3.10f1`
- Язык программирования: C#
- Рендеринг: Universal Render Pipeline
- Формат сохранений: JSON
- Основные внешние пакеты и библиотеки: Zenject, DOTween, TextMesh Pro, Starter Assets, Unity Input System

## Структура проекта

Основные папки с авторской логикой:

- `Assets/Scripts/Bootstrap` - меню, выбор уровней, общий прогресс.
- `Assets/Scripts/Player` - логика игрока, взаимодействие, порталы, сохранение.
- `Assets/Scripts/SaveSystem` - сохранение и загрузка данных.
- `Assets/Scripts/Door` - двери, условия открытия, проверка выражений.
- `Assets/Scripts/Level2` - обучающий уровень с циклами и технической системой.
- `Assets/Scripts/Level3` - логика артефактов и финальной двери.
- `Assets/Scripts/InheritanceLevel` - роботы, наследование, бой, разблокировка.
- `Assets/Scripts/UI` - интерфейсные элементы.

Подробная карта скриптов и архитектуры:

- `Assets/Scripts/README.md`

Основные сцены:

- `Bootstrap.unity` - стартовая сцена и меню.
- `Level1.unity` - первый игровой уровень.
- `Level2.unity` - уровень с механикой циклов.
- `Level3.unity` - уровень со сбором артефактов.
- `Level4.unity` - уровень с роботами и наследованием.

## Запуск проекта

1. Открыть проект в Unity `6000.3.10f1` или совместимой версии Unity 6.
2. Дождаться импорта пакетов и ассетов.
3. Открыть сцену `Assets/Scenes/Bootstrap.unity`.
4. Запустить проект через Play Mode.

## Назначение проекта

`C# Quest` предназначен для демонстрации того, как учебный материал по программированию можно представить в виде 3D-игры. Проект показывает связь между кодом и игровыми действиями: каждое программное понятие получает визуальное и интерактивное представление.

Игра может использоваться как дипломный проект, учебный прототип или основа для дальнейшего развития обучающих игровых механик по C#.
